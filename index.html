What's inside

Analysis and forecasting in one place

The platform does two jobs: it explains what happened between 2020 and 2025, and it projects what a given profile looks like up to 2035 using a model trained on that same history.

Historical analysis

Twelve interactive views across year, country, industry, company, revenue, ROI and use case — every one computed from the source file at request time.

Three models compared

Linear Regression, Decision Tree and Random Forest are trained on the same split and scored on MAE, RMSE and R². The winner is saved with Joblib and served from disk.

Forecasts to 2035

Pick a company, country, industry and target year. The model returns a maturity score, growth rate, ten-year trajectory and a recommendation tied to the predicted band.

Stated assumptions

Forecasts run under a scenario you choose. The dashboard shows exactly which assumptions each scenario applies, so a projection is never mistaken for a measurement.

Sample-size warnings

Segments backed by fewer than 60 records are flagged in place. Thin slices are excluded from the headline findings rather than quietly ranked alongside solid ones.

No external dependencies

Charts, animation and layout are hand-written in SVG, CSS and vanilla JavaScript. No chart library, no CSS framework, no CDN, no API calls.

Machine learning workflow

From raw file to forecast

Each stage runs in order. The numbered sequence reflects real execution order, not decoration.

01

Load and clean

Read 6,000 rows. Blank use cases become an explicit None category, since they mark non-adopters rather than missing data. Duplicates dropped.

02

Engineer features

Revenue spans six orders of magnitude, so it is log-scaled. Categoricals are one-hot encoded; numerics are standardised.

03

Train and compare

Three regressors fit on an 80/20 split, each scored on MAE, RMSE and R², with five-fold cross-validation as a stability check.

04

Select and persist

Models within 0.02 R² of the best score count as accuracy-equivalent; the tie is broken on response stability. The winner is refit on the full dataset and written to model.pkl with Joblib.

05

Project and predict

Features are rolled forward year by year under the chosen scenario, then passed through the saved pipeline for 2026–2035.

06

Visualise and advise

Results render as SVG charts alongside a recommendation keyed to the predicted maturity band.
